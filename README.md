# Multi-view RGB Rice Tiller Phenotyping

This repository provides the code for rice-plant segmentation and the subsequent skeleton-based, cross-view tiller-point association workflow.

## Environment setup

Python 3.10 or 3.11 is a reasonable starting point. The versions below are intentionally not pinned because PyTorch and torchvision packages depend on the operating system and CPU/CUDA configuration. Use mutually compatible PyTorch and torchvision builds.

```bash
python -m venv .venv
```

Activate the environment, then install the dependencies:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

For GPU inference, install a PyTorch/torchvision build matching your CUDA environment using the official instructions at <https://pytorch.org/get-started/locally/>. Then install any remaining packages from `requirements.txt`.

## 1. Test the segmentation model

### Input images

Place images to be tested in:

```text
test_data/test_images/
```

Run the script from the repository root:

```bash
python test_segmentation.py
```



## 2. Prepare the mask and skeleton folders

The current post-processing scripts expect images grouped into subfolders, typically one subfolder per plant, with matching filenames in the mask and skeleton folders. For example:

```text
outputs/
├── masks/
│   └── plant_001/
│       ├── view_001.png
│       ├── view_002.png
│       └── ...
└── skeletons/
    └── plant_001/
        ├── view_001.png
        ├── view_002.png
        └── ...
```

If segmentation outputs were produced in one flat directory, organize/copy the images into the required plant subfolders before running the current skeleton script. Keep each mask and its skeleton image under the same filename.

## 3. Extract skeletons

In `scripts/skeleton.py`, set `input_root_folder` to the root mask directory and `output_root_folder` to the desired skeleton directory. The current script processes subfolders of the input root; it does not process a flat root containing images only.

Run:

```bash
python scripts/skeleton.py
```

## 4. Detect candidate tiller points

In `scripts/tiller_candidates.py`, set these three paths in the `__main__` block:

- `mask_root`: root directory of the segmentation masks;
- `skel_root`: root directory of the skeleton images;
- `out_root`: directory for candidate-point outputs.

The mask and skeleton roots must contain matching plant subfolders, and the image filenames within each matching pair of folders must correspond.

Run:

```bash
python scripts/tiller_candidates.py
```

## 5. Provide the camera/view angles

The clustering script requires a `view_angles.csv` file in the output directory for the plant being processed. This file is **not** generated by `tiller_candidates.py`; prepare it from the actual image-acquisition metadata.

Required columns:

```csv
view,theta_deg
```

## 6. Run cross-view clustering

In `scripts/clustering.py`, set `out_root` in the `__main__` block to the candidate-output directory for **one plant**, containing the three CSV files from Step 4 and the `view_angles.csv` file from Step 5.

Run:

```bash
python scripts/clustering.py
```

## Important portability note

The current scripts contain local Windows paths in their `__main__` blocks. Edit those paths before running the scripts on another computer.
